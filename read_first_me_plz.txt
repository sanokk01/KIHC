KIHC 홈페이지를 현재 프로젝트 위에서 완성해줘.

이번 작업은 새 프로젝트를 만드는 것이 아니다.
먼저 현재 repository 구조와 기존 페이지/components/styles를 짧게 확인하고,
재사용 가능한 것은 최대한 유지한 채 필요한 부분만 수정/추가해라.

중요:
- 이미 구현된 것을 이유 없이 다시 만들지 말 것.
- 전체 프로젝트 리팩터링 금지.
- 사용하지 않을 추상화/라이브러리 추가 금지.
- 아래 요구사항 밖의 페이지나 기능을 임의로 추가하지 말 것.
- 디자인과 IA를 임의로 재해석하지 말 것.
- 현재 사용 중인 Next.js/React/TypeScript 구조와 스타일 방식을 우선 존중할 것.
- 작업 전에 장황한 계획을 출력하지 말고 repository를 확인한 뒤 바로 구현할 것.
- 완료 후 변경 파일, 구현 기능, 테스트 결과, DB 연결 포인트만 짧게 보고할 것.

==================================================
1. 사이트 성격
==================================================

기관:
KIHC 한국인재역량연구회

현재 제공된 KIHC 로고 asset을 사용한다.
기존 프로젝트에 로고가 이미 들어가 있다면 중복 복사하지 않는다.

사이트는 과장된 대형 연구기관 스타일보다
깔끔하고 신뢰감 있는 소규모 연구회 공식 홈페이지 느낌으로 만든다.

반응형:
- Desktop
- Tablet
- Mobile
모두 정상 사용 가능해야 한다.

11. DB 연결을 위한 구조
==================================================

DB는 이번 작업에서 실제 연결하지 않는다.

하지만 나중에 PostgreSQL / Supabase / 다른 DB 등으로
교체할 때 page/component를 다시 뜯어고치지 않도록
데이터 접근 계층을 분리한다.

예시 방향:

domain/content types
        ↓
repository interface
        ↓
temporary/mock repository
        ↓
services/use-cases
        ↓
pages/components

이름과 실제 folder 구조는 현재 repository convention에 맞게 결정해도 된다.

필요 domain model 예:

NewsPost
ResearchMaterial
PopupNotice
AboutContent
SiteSettings

Repository가 제공할 기능 예:

News:
- list
- getById / getBySlug
- create
- update
- delete

Research:
- list
- getById / getBySlug
- create
- update
- delete

Popup:
- getActive
- list
- create
- update
- delete

About:
- get
- update

Settings:
- get
- update

중요:
React component 안에서 직접 mock array를 import하여
데이터 구조를 고정하지 말 것.

Public page와 Admin이 같은 domain/service 계층을 사용하도록 한다.

DB 연결 시에는 repository implementation만 교체할 수 있어야 한다.

예:
MockContentRepository
→ DatabaseContentRepository

UI route와 component를 다시 작성하지 않는 구조가 목표.

이번 단계의 mock 데이터가 실제 DB처럼 영구 저장되는 척하지 말 것.
실제 persistence가 없는 부분은 명확하게 구분한다.

필요하다면 docs에 짧게:

"DB Integration"

섹션을 만들어
- repository implementation 교체 위치
- 필요한 tables/entities
- auth 연결 위치
- 문의 API 연결 위치

정도만 기록한다.

대형 설계 문서는 만들지 않는다.

13. 디자인 원칙
==================================================

사용자가 제공한 손그림 IA를 우선한다.

디자인은:
- 신뢰감 있는 연구기관/연구회

- navigation
- cards
- tables
- forms
- modal
이 깨지지 않도록 한다.
